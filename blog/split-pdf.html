How to Split a PDF and Extract Pages

When a long document contains only a few pages you need, splitting a PDF can create a smaller, focused file. Learn how page selections work and how to verify an extracted PDF.

By Tool Bazar · Published November 14, 2026 · Practical step-by-step guide

Open Tool Bazar tools →

What does it mean to split a PDF?

Splitting a PDF separates selected pages from the original document and saves those pages as a new PDF. It is different from deleting pages: the original file is not overwritten, and the selected pages become their own document.

How to extract PDF pages

  1. Open Tool Bazar and select Split PDF.
  2. Choose one PDF from your device.
  3. Enter the pages to extract, using numbers or ranges such as 1,3-5,8.
  4. Process the file and download the new PDF.
  5. Open the result and confirm the selected pages and their sequence.

How page ranges work

A comma separates selections and a hyphen marks a continuous range. For example, 2,5-7 selects page 2 followed by pages 5, 6 and 7. Page numbers start at 1. Enter only pages that exist in the source document; invalid selections should be corrected before processing.

When should you split a PDF?

Extract a chapter from a handbook, selected pages from a report, a receipt from a statement or a section from a class packet. If you need to keep most pages and remove only a few, use Delete PDF Pages. If you want to rearrange every page in one document, use Reorder PDF Pages.

Common questions

Does splitting change the original PDF?

No. The tool creates a separate output file and leaves your source file on your device.

Can I split a PDF online for free?

Yes, the Tool Bazar split tool is free to use in a modern browser.

Can I extract multiple page ranges?

Yes. Combine page numbers and ranges in one selection, then check the output order before sharing.

Before you share the result

Keep an untouched copy of the source file. Open the downloaded result and check page order, readability and any content that matters to your task. Editing a digitally signed PDF can affect its signature validity.
