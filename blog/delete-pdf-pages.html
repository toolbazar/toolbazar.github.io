How to Delete Pages from a PDF

Remove an unwanted blank sheet or an irrelevant section from a PDF. This guide explains how to delete selected pages and verify the new document.

By Tool Bazar · Published November 14, 2026 · Practical step-by-step guide

Open Tool Bazar tools →

When should you remove PDF pages?

Deleting pages is useful when a document contains accidental blank sheets, duplicate sections or material that should not be included in a copy you plan to share. Keep an untouched original in case you need to restore a removed page later.

How to delete pages from a PDF

  1. Open Tool Bazar and choose Delete PDF Pages.
  2. Select one PDF file.
  3. Enter the page numbers or ranges to remove, such as 2,5-7.
  4. Process the document and download the new PDF.
  5. Check the page count and confirm the pages before and after each deletion now meet as expected.

Select the pages to remove

Use commas for separate pages and a hyphen for a continuous range. For example, 2,5-7 removes page 2 and pages 5, 6 and 7. Make sure the numbers match the original PDF page count, not printed page labels that may differ.

Delete versus split

Delete PDF Pages keeps the pages you did not select and creates a new version without the selected pages. Split PDF does the opposite: it extracts the pages you specify into a separate document. If you only need to change page order, choose Reorder PDF Pages instead.

Common questions

Can I delete a single page?

Yes. Enter one page number in the selection field.

Does the tool overwrite my original?

No. It creates a new downloadable PDF and leaves the source file unchanged.

Can I restore a deleted page later?

Run the tool again from the original file or another copy that still contains the page.

Before you share the result

Keep an untouched copy of the source file. Open the downloaded result and check page order, readability and any content that matters to your task. Editing a digitally signed PDF can affect its signature validity.
