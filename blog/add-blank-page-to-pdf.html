How to add a blank page to a PDF

Add an empty sheet for notes, printing or document organization. Follow these steps to choose the insertion position and check the new page in your PDF.

By Tool Bazar · Published November 14, 2026 · Practical step-by-step guide

Open Tool Bazar tools →

Why add a blank page to a PDF?

A blank page can create room for handwritten notes, separate sections, provide a back side for duplex printing, or make a document easier to organize. Inserting a page is different from adding a text note: the new sheet starts empty.

How to insert a blank PDF page

  1. Open Tool Bazar and choose Add Blank Page in the Organize category.
  2. Select the PDF you want to update.
  3. Enter the position where the new page should appear. Position 1 inserts it at the beginning; position 2 places it after the first existing page.
  4. Click Process and wait for the new PDF to be prepared.
  5. Download the file and check the page immediately before and after the insertion point.

How page positions work

Positions are counted from 1, not 0. If your PDF has 8 pages, you can insert a blank page at positions 1 through 9. Position 1 puts the blank sheet first. Position 9 appends it after the current last page. A position between them inserts it into the sequence.

Example

For a 5-page PDF, entering position 3 produces this order: original page 1, original page 2, blank page, original page 3, original page 4, original page 5.

What size is the blank page?

Tool Bazar matches the new page to a nearby page in the PDF. This helps the inserted sheet fit naturally into a document whose pages share a common size. If your PDF mixes different page dimensions, inspect the inserted page carefully before printing or sharing.

Useful ways to use an inserted page

  • Notes: add an empty sheet after a section where readers may want to write.
  • Printing: create a blank separator or an empty reverse side for a duplex print workflow.
  • Organization: leave a visual break between two parts of a combined document.

What this tool does not do

The inserted page is blank. It does not automatically add a heading, page number, background, form fields or writing lines. If you need a label on every page, use the page-numbering or watermark tools separately. The new blank page may also affect printed page numbering that was already part of the original page artwork.

Common questions

Can I add more than one blank page?

This tool inserts one blank page per processing run. You can run it again on the downloaded result if you need another blank page, checking the new page count and position each time.

Can I put a blank page at the end?

Yes. Enter a position equal to the current page count plus one. For a 12-page document, position 13 adds the blank page at the end.

Can I insert a blank page into a signed PDF?

Changing a digitally signed PDF can affect signature validity. If the signature must remain verifiable, do not modify the signed original; ask the document issuer for an editable or unsigned copy.

Before you share the result

Open the downloaded PDF and check the page order, orientation and content. Editing a digitally signed PDF can affect its signature validity. Keep an untouched original if you may need it later.
